# Quick Start

## Install

```bash
npm install
```

## Run The Full Workflow

```bash
npm start
```

That command will:

1. Build the TypeScript project
2. Run the Jest suite
3. Generate plan, review, test, and ship artifacts

## Run Individual Steps

```bash
npm run build
npm test
npm run dev
```
